# GeoMath

A geometry calculator designed to help users calculate
geometric measurements with formulas and step-by-step solutions.

## About

GeoMath Calculator is a web-based mathematics tool
focused on geometry calculations.

The project currently focuses on 2D shapes,
starting with squares and rectangles.

## Features

- Kalkulator persegi
- Kalkulator persegi panjang
- Penghitungan model A
- Cara penghitungan
- Kalkulasi sisi
- Kalkulasi Diagonal
- Input dinamis

## Technologies

- HTML5

- JavaScript (Vanilla JS)

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run index.html using Live Server.
